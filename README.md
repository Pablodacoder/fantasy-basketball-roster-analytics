# Fantasy Basketball Roster Analytics

**Predictive NBA Trade & Roster Evaluator**. A web app that projects future fantasy points so managers can evaluate trades, find waiver pickups, and set daily lineups based on what players *will* do, not just what they've done.

## Features (planned)

- **Trade Evaluator**: projected fantasy point change for a proposed trade, with a Helps / Hurts / Roughly Even verdict and the top 3 reasons behind it
- **Schedule-aware projections**: accounts for games in the window, back-to-backs, opponent defense, and injuries
- **Waiver suggestions**: ranked add/drop moves by projected gain
- **Daily lineup optimizer**: recommends the best starting lineup each day
